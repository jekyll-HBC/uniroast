# WeRoast UI 重设计规格文档

**日期**：2026-04-05  
**策略**：高保真复刻 WeMust 视觉语言，仅替换内容，恶搞感来自内容反差而非视觉夸张。

---

## 1. 设计原则

- 颜色、字体、圆角、卡片风格全部沿用现有 `#1a7a1a` 绿色系
- 不引入新的 CSS 框架或字体
- 所有页面继续使用 Tailwind + 现有 CSS 变量

---

## 2. 登录页（`Login.jsx`）

**改动**：仅修改文案，布局不变。

| 元素 | 原内容 | 新内容 |
|------|--------|--------|
| 副标题 | （无或通用欢迎语） | 烤肉人，歡迎您～ |
| 登录方式 | 邮箱+密码表单 | 保持不变 |
| 注册入口 | 已有 | 保持不变 |

背景：深绿渐变 + 两个半透明装饰圆圈，保持现有实现。

---

## 3. 首页（`Home.jsx` + 新增顶部区域组件）

### 3.1 顶部绿色 Header 区域（替换原"今日主题"入口）

原版 WeMust 首页顶部结构复刻为"WeRoast"区域：

```
┌─────────────────────────────┐
│        WeRoast              │  ← 居中大字，白色，font-weight: 800
├─────────────────────────────┤
│  [⭐ 推荐]    [🔥 WeRoast]  │  ← 两个快捷图标，背景色各异
└─────────────────────────────┘
```

- 去掉原版扫码按钮和积分 pill
- 背景：`linear-gradient(160deg, #1a7a1a, #2d8c2d)`

### 3.2 应用图标网格（第二行，两排各4个，六边形图标）

| 图标 | 名称 | 跳转目标 |
|------|------|----------|
| 🎓 | Moodle | `/theme-feed`（主题库，Moodle 风格列表） |
| 📝 | 我的帖子 | `/profile` 帖子 tab |
| 🔥 | 今日最熱 | 按投票数排序的 feed |
| 🎲 | 隨機Roast | 随机跳转一条帖子 |
| ✏️ | 發帖 | 打开发帖弹窗 |
| 📣 | 意見反饋 | 反馈页（待实现） |
| 👥 | 好友 | 好友页（待实现） |
| 👑 | 會員 | 会员页（UI占位，后续开发） |

### 3.3 主题列表区域（替换原"最新公告/答辩通知"）

- Tab 标签：**今日主題**（绿色下划线激活）/ **每日主題**
- 右侧"更多"箭头
- 每条主题：绿色圆点 + 标题 + 日期/浏览数
- 删除原"今天日程"卡片

### 4.2 页面主体

| 区域 | 内容 |
|------|------|
| 绿色按钮 | ✦ 個人信息 → 跳转个人信息页 |
| 双列快捷 | 意見反饋 \| 會員 |

## 5. 个人信息页（新页面 `ProfileInfo.jsx`）

从"我的"页点击"個人信息"按钮进入，模态或新路由均可。

### 字段分组

**基本信息**（部分只读）：
- 头像（可点击更换）
- 用户名（可编辑）
- 姓名（只读，来自后端）
- 个人简介（可编辑）
- 性别（只读）
- 学院（只读）

**联系方式**：
- 大学邮箱（只读）
- 私人邮箱（可编辑）
- 手机号（可编辑，脱敏显示）

**账号安全**：
- 修改密码（跳转或弹窗）

顶部导航栏：返回 ‹ | 個人信息 | 保存

---

## 6. Moodle 主题库页（新页面）

仿 Moodle Dashboard 风格，展示所有主题：

- 顶部蓝色 header（保留 Moodle 配色作为恶搞对比）
- 筛选栏：进行中 / 主题名 / 列表视图
- 每条主题卡片：
  - 学院标签（灰色小字）
  - 主题标题（粗体）
  - 热度进度条（替换原"完成度"）
  - 参战人数

---

## 7. 现有功能对接

所有现有功能均保留，仅入口变化：

| 现有功能 | 新入口 |
|---------|--------|
| 推荐 Feed (`RecommendFeed`) | 首页第一行「推薦」按钮 |
| 今日主题 Feed | 首页第一行「WeRoast」按钮 |
| 所有主题列表 | 应用框「Moodle」→ 主题库页 |
| 发帖弹窗 | 应用框「發帖」 |
| 排行榜 (`/leaderboard`) | 应用框「今日最熱」复用 |
| 个人资料 (`/profile`) | 底部导航「我的」（不变） |
| 消息、主题详情、帖子详情 | 保持不变 |

需新建页面：个人信息页、Moodle主题库页、好友/意见反馈/会员占位页。

可复用组件：`FeedCard`、`RecommendFeed`、`ThemeFeed`、`ThemePage`、`PostDetail`、`Leaderboard` 全部保留。
