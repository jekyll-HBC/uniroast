# UniRoast UI 重设计：WeMust 恶搞皮肤

**日期**: 2026-04-04  
**状态**: 已确认，待实现  
**范围**: 全部前端页面视觉改造（交互逻辑不变）

---

## 背景

UniRoast 是针对澳门科技大学学生的恶搞评分平台，参考学校官方 App「WeMust」的 UI 风格做山寨克隆，乍看像 WeMust，细看全是槽点。

**核心原则：视觉换皮，交互不动。** 所有现有投票按钮、手势、动画效果（火焰粒子、下沉动画、打字机效果）完全保留。

---

## 设计方向：山寨克隆风（Option A）

高度复刻 WeMust 的绿色 UI + 布局结构，把每个功能名称替换成搞笑版本。

## 各页面改造说明

### 1. 登录页 `Login.jsx`

**风格**：深绿全屏（参考 WeMust 解锁页）

- 背景：`#1a7a1a` 纯深绿全屏
- 标题：「登录」白色大字
- 副标题：「欢迎来烤人 ～」（替换「歡迎您 ～」）
- 彩蛋文案：「请绘制求饶图案」（仅文字，无实际图案解锁功能）
- 输入框：半透明白色背景 `rgba(255,255,255,0.15)` + 白色边框
- 登录按钮：白底绿字
- 装饰元素：半透明白色圆圈（参考 WeMust 装饰风格）

### 2. 首页 `Home.jsx`

**风格**：高度还原 WeMust 首页布局

- 顶部 Header：`#1a7a1a` 绿色渐变 + 用户头像 + Tier 积分徽章（如「🔥 42 夯」替代「42 優」）
- 快捷按钮区：白色圆角卡片，4 个按钮
- 图标宫格：白色卡片，2 行 × 4 列，六边形图标改为圆角矩形
- 今日主题区：白色卡片 + 绿色左边框（参考 WeMust 日程样式）
- 最新烤闻区：白色卡片 + 绿色标签页

### 3. 主题详情页 `ThemePage.jsx`

**风格**：绿色 Hero 头部 + 白底帖子列表

- 顶部 Hero：`#1a7a1a` 绿色背景 + 大表情 + 主题名 + 参战人数
- **帖子展示方式保持原样**：帖子逐条列表（不分 Tier 分组网格）
- 每条帖子卡片：白底 + 用户名 + Tier 徽章 + 图片 + 投票数 + AI 评价入口
- 背景色：`#f5faf5`
- 参战 FAB：保留右下角，改为绿色

### 4. 帖子详情页 `PostDetail.jsx`

**视觉**：背景从黑色换白色系，其余全部不动

- 背景：`#ffffff` / `#f5faf5`
- Header：`#1a7a1a` 绿色 + 返回箭头 + Tier 徽章
- **以下全部保留原样，不做任何修改**：
  - 双击图片快速投票手势
  - 🔥「夯」投票按钮 + 火焰粒子特效
  - 💀「拉完了」投票按钮 + 下沉动画
  - Tier 等级变化弹入弹出动画
  - AI 评委打字机效果
  - 分享功能

### 5. 排行榜 `Leaderboard.jsx`

- Header：`#1a7a1a` 绿色 + 「🏆 战绩榜」
- 赛季切换按钮：绿色选中态 + 白色未选中
- 排名卡片：白底 + 绿色排名序号 + Tier 徽章 + 绿色分数

### 6. 个人资料 `Profile.jsx`

**风格**：参考 WeMust「我的」页

- 顶部：`#1a7a1a` 绿色背景 + 头像 + 用户名 + 邮箱（白色文字）
- 统计区：3格白色卡片（参战次数 / 总获票 / 最高 Tier）
- 功能列表：白底 + 右箭头（「我的战绩」「投票记录」「退出登录」）

### 7. 底部导航栏 `Navbar.jsx`

- 底栏背景：`#ffffff`
- 选中 Tab：`#1a7a1a` 绿色图标 + 文字
- 未选中 Tab：`#888888` 灰色
- 中间 FAB：`#1a7a1a` 绿色圆形按钮（替换原紫色）

## 实现注意事项

1. **只改 CSS 变量和颜色**，不重构组件逻辑
2. **图标宫格**的六边形样式（hexagon）改为圆角矩形（`border-radius: 10px`）
3. 首页「最新烤闻」区复用现有帖子列表数据，不需要新 API
4. 「快捷按钮」4 个全部跳转现有页面，无需后端支持
5. 「Moodle（提交参战）」图标点击触发现有上传弹窗逻辑
6. 登录页彩蛋文案「请绘制求饶图案」仅为静态文字

## 工作流（按 workflow.md）

实现时需遵循：
1. 先开 GitHub Issue（标题建议：`feat(frontend): WeMust 恶搞皮肤 UI 改造`）
2. 从 `develop` 建分支：`feature/ui-wemust-parody`
3. 写代码（按页面逐步改造，每页一个 commit）
4. 开 PR，CI 通过后合并
